# تطبيق أندرويد — سجل صيانة الدبابات

غلاف أصلي لملف النظام. الصفحة تُقدَّم من أصل `https` داخلي، فتعمل المزامنة عبر الرابط
بلا قيود `file://` التي تمنعها متصفحات سطح المكتب، وتُحفظ البيانات في تخزين هذا الأصل.

## بناء ملف APK — طريقتان

### أ) بلا تثبيت أي شيء (GitHub)
1. أنشئ مستودعاً جديداً على GitHub وارفع هذا المجلد كما هو.
2. تبويب **Actions** ← شغّل `build-apk` (أو ادفع أي تعديل على `main`).
3. بعد دقائق نزّل `dabbabat-apk` من المخرجات — بداخله `app-debug.apk`.
4. انقله إلى الجوال وثبّته (فعّل «تثبيت من مصادر غير معروفة»).

### ب) Android Studio
افتح المجلد ← انتظر المزامنة ← `Build ▸ Build APK(s)`.
الملف في `app/build/outputs/apk/debug/`.

## النسخة الأم والتحديث
- الملف المرفق في `app/src/main/assets/app.html` هو النسخة المدمجة داخل التطبيق.
- عند كل تشغيل يقرأ التطبيق رابط المزامنة من إعدادات الصفحة نفسها، ويطلب النسخة الأم
  (`?mode=app`). فإن وجد ملفاً مختلفاً نزّله وطبّقه عند إعادة الفتح.
- لتحديث الأجهزة كلها: ارفع ملف النظام الجديد إلى مجلد `DabbabatSync` في Drive
  باسم **`app-master.html`**. لا إعادة تثبيت ولا رفع APK جديد.
- **البيانات لا تُمسّ**: الدبابات والأوامر والمخزون والسجل في تخزين الأصل الداخلي،
  منفصلة تماماً عن ملف الصفحة.

## ما يدعمه الغلاف
- تخزين محلي و IndexedDB (الصور).
- اختيار الملفات للاستيراد (CSV/JSON) والكاميرا لصور الأعطال.
- تنزيل ملفات التصدير والنسخ الاحتياطية إلى مجلد **التنزيلات**.
- فتح روابط واتساب وغيرها في تطبيقاتها.

## للنشر الرسمي
`app/build.gradle` يوقّع نسخة الإصدار بمفتاح التصحيح للتجربة السريعة.
للتوزيع أنشئ keystore خاصاً وبدّل `signingConfig`.
